# Портфолио UX/UI-дизайнера Юрия Угарова

1. бургер-меню - есть
2. слайдер или карусель - нет (нарисовано то, что нарисовал дизайнер)
3. переключение категорий  - нет (нарисовано то, что нарисовал дизайнер)
4. модальное окно с информацией о выбранной карточке - при нажатии на проект открывается модалка
5. выбор параметров карточки и динамическое обновление связанной информации в модальном окне без перезагрузки страницы. - нет

Кастомный лендинг-портфолио, сделанный как домашнее задание курса **JavaScript** в [RS School](https://rs.school/). Вместо типового шаблона задания — одностраничный сайт реального дизайнера: тёмная тема, сетка на 8 колонок, кейсы, услуги и контакты.

CSS + Vanilla JS

Переключение светлой и темной темы с сохранением в Local Storage
